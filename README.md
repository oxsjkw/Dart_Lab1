## Ответы на вопросы
1. Чем статическая типизация Dart отличается от Python? Какое практическое
преимущество она даёт?
**Ответ:** в Python тип переменной проверяется в рантайме, а в Dart до запуска. преимущество в том, что ошибка будет обнаружена ещё до запуска.
2. Что означает String?? Чем отличается от String?
**Ответ:** String не может быть null, а String? может
3. Зачем в Dart final, если в Python можно просто договориться не менять
переменную?
**Ответ:** потому что можно договориться и забыть об этом, а когда написано final уже не забудешь
4. Чем именованный параметр {required String name} отличается от
позиционного? Приведите пример вызова.
**Ответ:** для позиционных параметров важен порядок, в котором они передаются в функцию, а для именованных не важен.
*Пример вызова:*
``` dart
describePet('Шарик', species='пёс');
```
